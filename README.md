Cada página contiene una base deliberadamente austera con el nombre del responsable y 4 consignas obligatorias.

Además, cada estudiante puede incorporar de manera opcional algún elemento adicional que, a su criterio,
mejore la presentación, la información o la funcionalidad de su página, siempre que mantenga coherencia con el sitio.

El `index.html` funciona como referencia visual y de navegación. Cada integrante deberá desarrollar su página manteniendo coherencia con el sitio principal.

Los archivos CSS y JavaScript son compartidos. Si fuera necesario modificarlos, deberán coordinarlo previamente con el resto del grupo para evitar conflictos.
